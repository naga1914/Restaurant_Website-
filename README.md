# Restaurant Website

Welcome to **Gourmet Delight**, a beautiful and responsive restaurant website designed to offer an immersive user experience with stunning visuals, interactive sliders, booking functionality, and more.

---

## 🌐 Live Demo

👉 [View Live](https://restaurant-website--bay.vercel.app/)  

---

## 🌟 Features

- ✅ **Modern Hero Section** with automated slider and dynamic heading/paragraph updates.
- 🍝 **Interactive Menu Sections** for different cuisines (Chinese, Italian, Japanese, Cocktail, Wine).
- 🎥 **Video Backgrounds** to enhance user engagement (bar section, visit section).
- 🥂 **Bar Section** with embedded promotional video and stylish layout.
- 🍷 **Slider for Popular Dishes** showcasing fine food with continuous scroll effect.
- 📅 **Table Booking Section** with inputs for number of people, date, and time.
- 📍 **Visit Us Section** with address, timings, and video background.
- 📞 **Footer Section** with contact info, about us, and quick navigation links.
- 🔼 **Scroll-to-Top Button** for better UX on long pages.

---

## 💡 Technologies Used

- **HTML5** – Structure and layout
- **CSS3** – Styling and animations (linked via `style.css`)
- **JavaScript** – Interactivity (slider logic, scroll effects in `script.js`)
- **Multimedia** – Videos and images to enhance aesthetics

## 🔧 Setup Instructions

1. **Clone the repository**  
   ```bash
   git clone https://github.com/your-username/restaurant-website.git
   cd restaurant-website
   ```

2. **Open in Browser**  
   Open `index.html` in any browser:
   ```bash
   open index.html
   ```
   Or just double-click the `index.html` file.
